# 🍔 Burger Website

A modern, responsive landing page for a fictional burger restaurant, built as a portfolio project. It features a clean single-page layout with smooth scroll navigation, animated sections, and a mobile-friendly menu.

## Live Demo

[jasseramir.github.io/burger-website/](https://jasseramir.github.io/burger-website/)

## Features

- Fully responsive design (mobile, tablet, desktop)
- Sticky header that adds a shadow on scroll
- Mobile navigation menu with open/close toggle
- Active link highlighting based on scroll position
- Scroll-to-top button
- Smooth reveal animations on scroll (via ScrollReveal)
- Sections: Home, About, Popular Products, Why Us, Contact

## Built With

- HTML5
- CSS3
- JavaScript (Vanilla)
- [ScrollReveal](https://scrollrevealjs.org/) — scroll animations
- [RemixIcon](https://remixicon.com/) — icon set

## Getting Started

No build tools or dependencies required — it's a static website.

1. Clone the repository
   ```
   git clone https://github.com/jasseramir/burger-website.git
   ```
2. Open `index.html` in your browser

That's it 🎉
